# Atul Kumar Dubey — Data & Analytics Portfolio

A responsive React + Vite portfolio based on the supplied resume. The design uses a dark navy theme with blue/cyan accents and includes projects, technical skills, experience, education, certification, and contact details.

## Requirements
- Node.js 18+ (recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Build for production
```bash
npm run build
npm run preview
```

## Resume

## Contact form
The form validates required fields and opens the visitor's default email application with a prefilled message. It does not send messages through a backend or store submitted data. For a server-backed form, configure a trusted form service or your own backend before publishing.

## Deploy to Vercel
1. Create a GitHub repository and upload the project files.
2. Sign in to Vercel and import that repository.
3. Use the default Vite settings: build command `npm run build`, output directory `dist`.
4. Deploy and test the site on mobile and desktop.
5. Add the deployed portfolio URL to your resume and LinkedIn profile.
